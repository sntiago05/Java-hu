# Corporate Talent Hub

Programa de consola en **Java** que simula la gestión del talento humano en una empresa: empleados y datos de la empresa.

## Contenido
- `modelo/Empleado.java` y `modelo/EmpresaRecord.java` (uso de `record`)
- `documentacion/NotasArquitectura.java`: notas de diseño del ejercicio
- `App.java`: punto de entrada

## Cómo ejecutar
Ejecuta `App` desde el IDE o con Maven.

## Proyecto de aprendizaje
Práctica de clases, `record` y modelado básico.
